# TOEIC Reading Test

Web thi thử TOEIC Reading (Part 5–7, câu 101–200) cho 30 đề ETS 2022–2024. Chạy hoàn toàn offline, có sẵn đáp án, dùng được trên máy tính và iPhone/iPad (cài như app).

- Phiếu trả lời, đồng hồ (tự nộp khi hết giờ), tự lưu và làm tiếp, chấm điểm theo từng Part, điểm Reading ước tính, xem lại câu sai.
- Đáp án: ETS 2023 & 2022 chép từ bảng đáp án gốc; ETS 2024 do AI giải (có nhãn 🤖, có thể sai vài câu, sửa được trong app). Bảng đáp án: [DAP-AN.txt](DAP-AN.txt).
- Đề thi **không** nằm trong repo. Nạp đề từ file của bạn: nút **📁 Gắn đề từ máy** (PDF hoặc `.md`), hoặc đặt thư mục `goi-de/` cạnh `index.html` (tạo bằng nút **📦 Xuất gói đề**). Không đăng nội dung đề công khai.

## Dùng trên máy tính
Tải repo (Code → Download ZIP), giải nén, mở `index.html`.

## Cài trên iPhone
1. Bật GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / (root) → Save**. Địa chỉ: `https://<tên-tài-khoản>.github.io/<tên-repo>/`.
2. Mở địa chỉ đó bằng Safari → **Chia sẻ → Thêm vào MH chính**.
3. Mở app trên màn hình chính → **📁 Gắn đề từ máy** → chọn các file đề trong ứng dụng Tệp.

Chi tiết: [README.txt](README.txt).

Thư viện kèm theo: pdf.js 3.11.174 (Mozilla, Apache-2.0) trong `vendor/pdfjs/`.
